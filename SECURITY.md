# Security policy

## Reporting a vulnerability

Please do not disclose API keys, passwords, tokens, personal data, or a proof of concept for an exploitable issue in a public issue or pull request.

Use GitHub's private vulnerability reporting or Security Advisory workflow for this repository when available. If private reporting is not enabled, contact the repository owner through their GitHub profile and include only the minimum reproducible details.

If a credential has been committed, revoke or rotate it immediately before reporting the incident. Removing the file from the latest commit does not remove it from Git history.

## Supported versions

This is an educational open-source project. Only the latest `main` revision is expected to receive security fixes.
